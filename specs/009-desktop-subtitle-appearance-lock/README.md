# 桌面字幕外观设置与鼠标穿透锁定

## Overview

为已实现的桌面字幕增加不透明度、字体样式与锁定功能。锁定后字幕仍显示、更新，但鼠标点击、滚动和拖动应穿透整个原生窗口，不影响下方应用。主窗口始终保留解锁入口。

## Design

- 新增七项 `desktop_subtitle_*` 持久化配置：不透明度 0.2–1、字体枚举、字号 16–64、六位颜色、粗体、斜体、锁定；旧设置默认不锁定，保留既有字号及不透明度。
- 既有字幕载荷增加 `appearance` 和 `locked`。前后端归一化数值、颜色与字体白名单；外观即时更新已有字幕，不重启识别、改变音频或修改历史。
- 主窗口滑杆和颜色选择支持即时预览、确认后保存；保存中的改动、排队改动与其他尚未确认的预览分别合并，保存失败恢复相应持久化值。
- 字幕悬停提供「锁定」，通过 `lock_desktop_subtitle` 命令发送 `desktop-subtitle-lock-requested` 给主窗口，再由现有串行更新管道下发锁定状态，避免旧流式载荷意外解锁。
- 原生窗口 `set_ignore_cursor_events(locked)` 实现鼠标穿透，`set_resizable(!locked)` 防止边框阻挡。字幕前端同时隐藏操作按钮、禁止拖动，主窗口菜单和显示设置支持解锁，重开或重启保持锁定偏好。
- 不透明度只影响文本；字体和颜色使用安全 CSS 属性。短窗口先减少完整文本行数，再缩小过大的字号，避免半行裁切。中英文使用说明见[实时字幕](../../docs/live-subtitles.md)。
