# 实时通话音频恢复、原声译音混音与启动偏好

## Overview

停止通话后恢复电脑默认麦克风与播放设备；实时页独立控制发给对方的原声、译音及音量；已有配置不再每次启动进入引擎选择页。

本次声音控制针对 Qwen 双向通话，原声指真实麦克风原声；仅字幕模式及其他引擎不变。

## Design

- `system_devices` 使用稳定设备标识持久化恢复记录，切换前固定真实采集设备，恢复包含系统输入、输出和 Windows 通信角色。手动预先切到虚拟默认时使用明确选定的真实设备作为恢复目标。
- macOS 使用 CoreAudio；Windows 集中封装 IPolicyConfig。自动配对限 BlackHole／标准名 VB-CABLE；可关闭自动管理使用已有手动路由。
- 原生 `PlaybackMixer` 两路独立队列与采样率转换，直接接收麦克风 PCM，与云端译音混音。默认原声关、译音开，增益 0–1；静音同时清队列。
- Qwen 控制器在停止、取消启动与失败时清理输出并恢复设备；退出原生兜底、下次启动恢复异常退出记录。
- 控件即时生效，设置串行合并写入防止与引擎／字幕偏好相互覆盖。记忆引擎与首次选择在同一写入中提交。
- 使用说明见 [Qwen 双向通话](../../docs/qwen-duplex.md)。
