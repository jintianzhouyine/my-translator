# 诊断日志目录与最近七天保留

## Overview

为 Windows 实时翻译中断提供可分享的本地诊断记录。按本机日期保留今天及前 6 天的日志，用户可以从「设置 → 关于」打开目录。

## Design

- 目录固定为 `app_data_dir()/logs`，文件名 `translator-YYYY-MM-DD.log`；日期与带时区的时间由原生端生成。
- 独立 std 日志核心串行追加，单条正文上限 4 KiB、每日上限 5 MiB，达到上限只写一次提示。只删除严格匹配日期文件名的普通文件，不处理其他文件/目录/符号链接。
- 启动、首次跨日写入、打开目录及每小时维护清理过期文件；退出后不运行后台任务，下次启动补做。
- 前端与原生双重白名单，记录版本、平台、启停、引擎、状态、方向、重试次数和错误类别。原始错误只在内存分类，不落盘密钥、设置、字幕、录音、文件路径、设备名或完整服务端正文；未处理的前端异常只记录发生。
- 前端写入异步有界（最多 64 项、单次 2 秒），失败不会中断翻译。原生 Qwen/OpenAI 会话及采集/播放异常直接写入固定事件。
- 新增命令 `write_diagnostic_event`、`get_diagnostic_log_info`、`open_diagnostic_log_dir`；浏览器预览明确不保存桌面日志。
- 使用说明见 [诊断日志](../../docs/diagnostics.md)。
