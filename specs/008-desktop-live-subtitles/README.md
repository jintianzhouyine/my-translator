# 桌面歌词式实时字幕

## Overview

新增桌面歌词式实时字幕，允许独立开关、原文／译文／双语以及自己／对方／双方筛选。复用正在运行的识别与翻译结果，偏好自动保存，不改变采集、译音或会话历史。

## Design

- 独立透明、置顶、跨工作区的 Tauri 窗口 `desktop-subtitle`，初次在当前屏幕底部居中，支持拖动和缩放，不抢输入焦点。关闭时隐藏并通知主窗口保存关闭状态。
- `TranscriptUI.onChange` 提供原始文本快照，桌面投影选择最近一个符合条件的句子；Qwen 按方向与句子 ID 处理延迟原文，其他引擎按每句记录的采集来源筛选。混合采集无法可靠区分双方，只在选择双方时显示。
- 三项 `desktop_subtitle_*` 设置独立于主窗口 `show_original`；动态切换只更新字幕。主窗口序列化保存，原生及前端合并串行更新，处理关闭与保存并发。
- IPC 为 `set_desktop_subtitle`、`get_desktop_subtitle`、`close_desktop_subtitle`，事件为 `desktop-subtitle-update`、`desktop-subtitle-closed`；窗口初始化先监听再读快照，避免加载期间丢字幕。
- 字幕文本用 `textContent`，独立窗口只接收选中的显示文本及标签；权限限于事件订阅与拖动。浏览器 mock 支持字幕预览，不替代原生验收。使用说明见[实时双语字幕](../../docs/live-subtitles.md)。
