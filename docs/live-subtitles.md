# 实时双语字幕

在「设置 → 显示设置」开启 **双语字幕（原文＋译文）**，实时字幕会按每段原文在上、译文在下显示；关闭后仅显示译文。也可通过实时字幕的「更多 → 双语字幕」切换。切换后即时生效并保存，下次启动沿用，不会暂停通话或改变音频输出。

「更多」中的双栏对照按钮可切换为原文、译文左右并排。关闭双语字幕时暂时收起原文栏，再开启会恢复当前选择的排版。显示内容开关会保存；双栏/上下排版仍为本次运行的选择。

原文和译文可能先后到达。Qwen 按服务返回的句子 ID 关联两者；译文先到时显示「等待原文…」，原文到达后补到同一段，不用译文反向生成原文。Qwen 3.8 的识别默认开启，无需额外配置 ASR 接口。Soniox、OpenAI 和本地模式在已返回原文时也适用此显示开关。

复制、保存会话仍保留已收到的原文和译文，显示开关不会删改历史记录。音频文件翻译的显示及导出选项独立于实时字幕。

本次自动化验证覆盖单栏/双栏切换、显示设置保存失败恢复、通话中无中断切换，以及 Qwen 原文延迟返回和乱序关联。实际云端识别效果仍需用自己的 API 和会议音频验证。

Qwen 官方说明：[客户端事件及默认 ASR](https://help.aliyun.com/zh/model-studio/live-translator-client-events)、[服务端识别与译文事件](https://help.aliyun.com/zh/model-studio/live-translator-server-events)。
