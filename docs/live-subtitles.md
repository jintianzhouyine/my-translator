# 实时双语字幕

[中文](live-subtitles.md) · [English](live-subtitles.en.md) · [文档目录](README.md)

在「设置 → 显示设置」开启 **双语字幕（原文＋译文）**，实时字幕会按每段原文在上、译文在下显示；关闭后仅显示译文。也可通过实时字幕的「更多 → 双语字幕」切换。切换后即时生效并保存，下次启动沿用，不会暂停通话或改变音频输出。

「更多」中的双栏对照按钮可切换为原文、译文左右并排。关闭双语字幕时暂时收起原文栏，再开启会恢复当前选择的排版。显示内容开关会保存；双栏/上下排版仍为本次运行的选择。

原文和译文可能先后到达。Qwen 按服务返回的句子 ID 关联两者；译文先到时显示「等待原文…」，原文到达后补到同一段，不用译文反向生成原文。Qwen 3.8 的识别默认开启，无需额外配置 ASR 接口。Soniox、OpenAI 和本地模式在已返回原文时也适用此显示开关。

复制、保存会话仍保留已收到的原文和译文，显示开关不会删改历史记录。音频文件翻译的显示及导出选项独立于实时字幕。

在「设置 → 显示设置 → 桌面字幕」开启独立的透明置顶字幕窗口，像桌面歌词一样显示最近一句话。也可用实时页的「更多 → 桌面字幕」开关。拖动字幕调整位置，悬停时显示关闭按钮；关闭该窗口也会关闭开关。

桌面字幕可选「原文＋译文」「仅原文」「仅译文」，以及「自己的话」「对方的话」「双方的话」，默认关闭，默认内容为自己的原文＋译文。选择即时生效并自动保存，下次启动沿用，不影响主窗口的双语设置、识别、译音或会话记录。原文和译文按同一句话更新；尚未返回的内容不会用上一句话补齐。

同一区域可调整桌面字幕的不透明度（20%–100%）、字体（系统默认／无衬线／衬线／等宽）、字号（16–64px）、颜色、粗体和斜体。不透明度只影响字幕文字，悬停操作按钮保持清晰。拖动滑杆或选色时即时预览，松开或确认后自动保存；保存失败会恢复上次保存的值。窗口高度较小时优先减少显示行数，再缩小过大的字号，避免字被截掉一半；放大字幕窗口可容纳更大的字。

在字幕上悬停并点击「锁定」，或在设置中开启「锁定桌面字幕（鼠标穿透）」。锁定后整个字幕窗口不接收鼠标输入，点击、滚动和拖动会落到下方应用；字幕不能移动或缩放，悬停按钮隐藏，字幕仍持续更新。可从主窗口「更多 → 解锁桌面字幕」或「设置 → 显示设置」取消锁定；主窗口的解锁入口始终保留。锁定状态会自动保存，重新启动或关闭后再打开字幕时继续沿用。

Qwen 双向通话通过双方独立音频区分自己和对方；关闭双向通话后只采集对方声音，选择「自己的话」会等待自己的声音。其他实时引擎把麦克风视为自己、系统声音视为对方；同时采集两者时无法可靠区分来源，请选择「双方的话」。字幕复用当前翻译的结果，不会额外启动麦克风、云端识别或产生一条新的翻译会话。清空主窗口字幕也会清空桌面字幕，暂停或停止保留最近一句便于阅读。

实时翻译遇到短暂网络中断或服务端结束连接时，会显示连接状态并自动重连，连续失败最多重试 3 次。Qwen 双向通话只恢复断开的方向，另一方向继续工作；OpenAI 重连不会重复启动音频采集。Soniox 的会话轮换失败时，只要原连接仍可用就继续使用原连接。

点击暂停或停止会取消待执行的重连。密钥、余额、配置等需要处理的错误，以及重试耗尽或音频设备异常，会明确提示并退出运行状态，避免按钮仍显示翻译中却没有输出。恢复连接后继续处理新收到的声音；网络中断期间的声音不会补发，已有字幕和会话记录保留。正常静音不会触发字幕超时判断。

本次自动化验证覆盖单栏/双栏切换、显示设置保存失败恢复、通话中无中断切换，以及 Qwen 原文延迟返回和乱序关联。实际云端识别效果仍需用自己的 API 和会议音频验证。
