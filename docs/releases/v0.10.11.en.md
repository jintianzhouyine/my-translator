Add desktop caption opacity, font styling and a lock that lets mouse input reach the app underneath.

## Changes

- In **设置 → 显示设置 → 桌面字幕** (Settings → Display → Desktop captions), adjust opacity (20–100%), font family, size (16–64px), color, bold and italic. Sliders and color selection preview immediately and save on confirmation; failed saves restore persisted values.
- The caption hover controls now include **锁定** (Lock). Locking uses the native window API to pass clicks, scrolling and drags through the captions, while disabling caption dragging, resizing and hover controls. Captions keep updating.
- Restore interaction through **更多 → 解锁桌面字幕** (More → Unlock desktop captions) in the main window or through display settings. Lock state is saved across app restarts and caption reopening.
- Appearance and lock preferences remain independent of the main window's fonts and audio settings. Changes do not interrupt capture, recognition or narration. Lock requests use the serialized caption update queue so older streaming updates cannot undo them. Existing settings files remain compatible.
- Larger fonts reduce the number of complete visible lines before adapting to window height. Narrow windows no longer clip large italic glyphs or ellipses at the edge.

See [live and desktop captions](https://github.com/jintianzhouyine/my-translator/blob/v0.10.11/docs/live-subtitles.en.md).

## Manual build

This version is prepared as a Release draft for you to trigger manually. In [Build & Release](https://github.com/jintianzhouyine/my-translator/actions/workflows/release.yml), click **Run workflow**, select **main**, and enter **`v0.10.11`**.

After both platforms pass, the workflow uploads and publishes:

- `MyTranslator_0.10.11_aarch64.dmg`
- `MyTranslator_0.10.11_x64-setup.exe`
- `SHA256SUMS`

## Validation scope

All 383 JavaScript application tests and five Rust module tests passed. The native caption module passed type checking against Tauri 2.10.3. Checks cover appearance normalization, settings compatibility, persistence and rollback, concurrent locking, main-window unlocking and uninterrupted audio and narration.

Browser checks covered 320/400/900px windows, 16/64px font sizes, 20/55/100% opacity, preview and persistence, main-window unlocking and page clicks reaching an underlying button. Version consistency, formatting of modified Rust files, Git diff checks and strict LeanSpec validation passed.

Page hit testing does not verify native window behavior. Passing clicks, scrolling and drags to other apps on macOS and Windows has not been tested on real windows. Complete native packaging and real calls were not verified; complete platform tests and installer results depend on the manual CI run.
