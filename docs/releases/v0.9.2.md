简体中文界面的首个 ARM64 安装包版本。

## 下载

- **macOS M 系列（Apple Silicon）**：下载文件名包含 `aarch64` 的 `.dmg`，适用于 M1 及更新的 M 系列芯片。
- **Windows ARM64**：下载文件名包含 `arm64` 的 `-setup.exe`。应用程序为原生 ARM64；NSIS 安装器本身使用 x86 引导程序。
- `SHA256SUMS` 提供安装包的 SHA-256 校验值。

## 更新内容

- 将主界面、设置、语言列表、朗读、翻译记录、快捷键及常见提示改为简体中文。
- 补齐 Windows ARM64 的 sherpa-onnx 本地朗读库构建配置。
- 修复 macOS 专属链接参数被传给 Windows 编译器的问题。
- 构建后检查实际应用程序的 Mach-O／PE 架构，确保两个版本均为原生 ARM64。

## 使用说明

- 云端翻译需要自行配置 Soniox、OpenAI 或 Qwen API 密钥，服务费用由对应提供商收取。
- 本地 MLX 翻译仅支持 Apple Silicon Mac；Windows ARM64 支持云端翻译及本地／在线朗读。
- **macOS 包使用 ad-hoc 本地签名，未经过 Apple 开发者签名及公证。Windows 安装包未使用发行者证书签名。系统可能显示无法验证发行者的提示。**
- 本次未配置独立的自动更新签名密钥，请从本仓库 Releases 手动下载后续版本。
- 构建和架构检查不等同于真实设备上的通话兼容性测试。本版本尚未实现把翻译语音送入会议软件虚拟麦克风的功能。
