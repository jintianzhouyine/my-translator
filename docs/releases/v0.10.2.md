修复 Windows x64 构建在语音库准备阶段长时间无输出的问题。

## 更新内容

- 下载、校验和解压分阶段输出日志；长步骤周期输出进度或耗时。
- 下载增加连接、低速及整体超时，最多尝试三次；解压同样有时间上限。
- 对官方语音库压缩包校验大小及 SHA-256，校验通过后才使用。
- 校验后的语音库独立缓存，避免后续构建反复下载。
- 保留 Mac M 系列与 Windows x64 发布组合，翻译功能与模型不变。

## 下载

- **Mac M 系列**：`MyTranslator_0.10.2_aarch64.dmg`。
- **Windows x64（Intel/AMD 64 位）**：`MyTranslator_0.10.2_x64-setup.exe`。
- `SHA256SUMS` 提供安装包校验值。

Windows ARM64 的历史安装包仍可在 [v0.10.0](https://github.com/jintianzhouyine/my-translator/releases/tag/v0.10.0) 获取。
音频自动解码和切分仍需另外安装 FFmpeg / ffprobe；通话译音输出需要兼容的虚拟音频设备。
Qwen 功能需自行配置百炼 API Key、业务空间及地域。

## 验证范围

发布流程执行两个平台的 JavaScript / Rust 测试、安装包构建及架构和版本检查，全部成功后发布附件。
新增回归测试覆盖下载失败重试、损坏压缩包拒绝、缓存恢复及子进程超时。
真实设备安装、云端翻译与会议音频路由仍需在目标电脑上验证。

macOS 使用 ad-hoc 签名，未经 Apple 开发者签名和公证；Windows 安装包未使用发行者证书签名。
