实时双语字幕与当前仓库更新入口。

## 更新内容

- 修复「显示原文」设置未生效的问题，支持原文在上、译文在下的双语字幕，也可仅显示译文。
- 在「设置 → 显示设置」及实时字幕「更多」菜单中切换双语显示，立即保存，不中断通话或改变译音输出。
- 保留原文、译文左右双栏对照；Qwen 原文晚到时自动补到对应字幕，保持原文与译文的消息关联。
- GitHub 项目仓库、问题反馈和更新检查统一指向 `jintianzhouyine/my-translator`。
- 更新检查读取本仓库的最新正式 Release，发现新版后打开下载页；修复检查失败却显示「已是最新版本」的问题。
- 移除未使用的自动安装、重启及旧更新插件配置。当前版本采用手动下载安装包，不会在应用内自动安装更新。

## 安装包

手动触发构建后，工作流会在两个平台的测试、打包与架构检查全部通过时，上传并发布以下附件：

- **Mac M 系列**：`MyTranslator_0.10.4_aarch64.dmg`。
- **Windows x64（Intel/AMD 64 位）**：`MyTranslator_0.10.4_x64-setup.exe`。
- `SHA256SUMS`：安装包校验值。

## 验证范围

261 项 JavaScript 测试通过，覆盖字幕切换、设置保存失败恢复、原文延迟关联、版本比较和更新失败提示；浏览器预览已检查双语开关及仓库链接。
本机 Rust 测试受 ScreenCaptureKit 与 Swift SDK 编译兼容问题阻止，原生测试和安装包构建以本次 CI 结果为准。真实设备安装、云端翻译与会议音频路由仍需在目标电脑验证。

macOS 使用 ad-hoc 签名，未经 Apple 开发者签名和公证；Windows 安装包未使用发行者证书签名。
