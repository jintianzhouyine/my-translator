The first ARM64 installer release with a Simplified Chinese interface.

## Downloads

- **macOS Apple Silicon**: download the `.dmg` whose filename contains `aarch64`, for M1 and newer M-series chips.
- **Windows ARM64**: download the `-setup.exe` whose filename contains `arm64`. The application is native ARM64; the NSIS installer itself uses an x86 bootstrapper.
- `SHA256SUMS` contains SHA-256 checksums for the installers.

## Changes

- Translated the main interface, settings, language lists, Read mode, translation history, shortcuts and common messages into Simplified Chinese.
- Added Windows ARM64 build configuration for sherpa-onnx local speech synthesis.
- Fixed macOS-specific linker arguments being passed to the Windows compiler.
- Added post-build checks of the application's Mach-O / PE architecture to ensure that both builds are native ARM64.

## Usage notes

- Cloud translation requires your own Soniox, OpenAI or Qwen API key. The respective provider charges for usage.
- Local MLX translation supports Apple Silicon Macs only. Windows ARM64 supports cloud translation and local / online speech synthesis.
- **The macOS package uses an ad-hoc signature, without an Apple Developer signature or notarization. The Windows installer has no publisher certificate. Your operating system may display an unverified-publisher warning.**
- This release did not configure a separate signing key for automatic updates. Download later versions manually from this repository's Releases.
- Build and architecture checks do not establish call compatibility on real devices. This version had not yet implemented sending translated speech to a meeting application's virtual microphone.
