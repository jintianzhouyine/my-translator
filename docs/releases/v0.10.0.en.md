Qwen duplex calls, terminology imports and audio-file translation.

## Downloads

- **macOS Apple Silicon**: download `MyTranslator_0.10.0_aarch64.dmg`, for M1 and newer M-series chips.
- **Windows ARM64**: download the `-setup.exe` whose filename contains `arm64`. The application is native ARM64; the NSIS installer uses an x86 bootstrapper.
- `SHA256SUMS` contains SHA-256 checksums for both installers.

## Changes

- Added Qwen duplex calls: translate microphone speech and send it to a selected virtual audio device, while a separate session displays captions for the other party on your computer. Caption-only mode is also available.
- Separate target languages and terminology dictionaries for each direction, using Bailian's Beijing or Singapore region.
- Import terminology from Excel (`.xlsx`), CSV, TSV, TXT or JSON, with worksheet selection, preview, merge, replacement, conflict handling and column swapping.
- Added audio-file translation: generate timestamped source text and translations, click captions to replay the corresponding original audio, and export SRT, VTT or TXT.
- Long recordings support automatic splitting, custom split points and manual import of pre-split files.
- File translation runs up to two requests concurrently by default, displays translations as they arrive, and automatically retries transient errors up to twice.
- Only failed request segments can be skipped. Retry failed segments individually while keeping completed results and the original timeline. After cancellation, unfinished work can be resumed within the current window.
- Improved audio routing, session cleanup, connection errors and preservation of partial captions during retries.

## Usage notes

- This Qwen implementation uses `qwen3.8-livetranslate-flash-realtime`. Configure your own Alibaba Cloud Bailian API key, workspace and region. Duplex calls use two billable sessions; failed retries may incur additional usage. Doubao ASR / AST is not integrated.
- **Full automatic decoding and splitting of audio files require FFmpeg and ffprobe installed locally. They are not bundled.** If these tools are missing, use “Import split audio” on the page.
- Local source splitting supports up to 16 GiB / 24 hours. Each manually imported file supports up to 100 MiB / 30 minutes. Translation speed depends on the network, provider rate limits and recording length.
- Sending translated speech to a meeting application requires a separately installed virtual audio driver and matching device selections in both applications. Windows ARM64 requires an ARM64-compatible driver.
- macOS live capture requires Microphone and Screen & System Audio Recording permissions. Uploaded-file translation does not require these capture permissions.
- macOS uses an ad-hoc signature, without an Apple Developer signature or notarization. The Windows installer has no publisher certificate.
- Automatic update publishing is not configured for this repository. Download updates manually from Releases. File-translation results and resumable queues exist only in the current window; export captions before exiting.

## Validation scope

- Before release, 209 local JavaScript tests passed. The features also passed 27 native macOS Rust tests and an Apple Silicon debug build.
- A local mock service verified that one request could fail while other segments completed, that the failed request could be skipped, and that retrying it could succeed without duplicating completed captions.
- The release workflow runs JavaScript / Rust tests, builds, and binary architecture and version checks for macOS Apple Silicon and Windows ARM64, publishing installers after success.
- Builds and mock tests do not establish real cloud translation quality, timestamp alignment or meeting-call behavior on target devices. Validate with your own account, recordings and audio devices.
