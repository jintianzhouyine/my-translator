Live bilingual captions and update links for this repository.

## Changes

- Fixed the “Show source text” setting. Captions can display source text above the translation, or the translation alone.
- Toggle bilingual display in Settings → Display settings or the live-caption More menu. The choice is saved immediately without interrupting the call or changing translated audio output.
- Retained side-by-side source and translation panels. Late Qwen source text is added to the corresponding caption while preserving its association with the translation.
- GitHub repository links, issue reporting and update checks now all point to `jintianzhouyine/my-translator`.
- Update checks read this repository's latest published Release and open its download page when a newer version is available. Fixed failed checks incorrectly reporting “Already up to date.”
- Removed unused automatic installation, restart and old updater-plugin configuration. Updates are downloaded and installed manually; the application does not install them automatically.

## Installers

After a manual build is triggered, the workflow uploads and publishes these attachments only after tests, packaging and architecture checks pass on both platforms:

- **Apple Silicon Mac**: `MyTranslator_0.10.4_aarch64.dmg`.
- **Windows x64 (Intel/AMD 64-bit)**: `MyTranslator_0.10.4_x64-setup.exe`.
- `SHA256SUMS`: installer checksums.

## Validation scope

261 JavaScript tests passed, covering caption switching, recovery from settings-save failures, late source-text association, version comparison and update failure messages. Browser previews checked the bilingual toggle and repository links.
Local Rust tests were blocked by ScreenCaptureKit / Swift SDK build compatibility problems. Native tests and installer builds depend on this version's CI result. Installation on real devices, cloud translation and meeting audio routing still require validation on target computers.

macOS uses an ad-hoc signature, without an Apple Developer signature or notarization. The Windows installer has no publisher certificate.
