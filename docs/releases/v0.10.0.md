Qwen 双向通话、术语词典导入与音频文件翻译版本。

## 下载

- **macOS M 系列（Apple Silicon）**：下载 `MyTranslator_0.10.0_aarch64.dmg`，适用于 M1 及更新的 M 系列芯片。
- **Windows ARM64**：下载文件名包含 `arm64` 的 `-setup.exe`。应用程序为原生 ARM64；NSIS 安装器使用 x86 引导程序。
- `SHA256SUMS` 提供两个安装包的 SHA-256 校验值。

## 更新内容

- 新增 Qwen 双向通话链路：麦克风语音翻译后输出到指定虚拟音频设备，对方声音通过独立会话显示本机字幕；支持仅字幕模式。
- 两个方向可分别设置目标语言和术语词典，使用百炼北京或新加坡地域配置。
- 支持从 Excel（.xlsx）、CSV、TSV、TXT、JSON 导入术语，提供工作表选择、预览、合并、替换、冲突处理及两列互换。
- 新增音频文件翻译：生成带时间轴的原文与译文，点击字幕回放对应原音频，导出 SRT、VTT 或 TXT。
- 长录音支持自动分段、自定义分割点和手动导入已切分文件。
- 文件翻译默认最多两段并行，显示正在生成的译文，临时错误最多自动重试两次。
- 只对请求失败的片段提供跳过操作；可单独重试失败片段，保留已完成结果和原始时间轴。取消后可在当前窗口继续未完成任务。
- 改进音频路由、会话清理、连接错误提示以及重试时的部分字幕保留。

## 使用说明

- 本版 Qwen 链路使用 `qwen3.8-livetranslate-flash-realtime`，需自行配置阿里云百炼 API Key、业务空间和地域；双向通话按两个会话计费，失败重试也可能产生额外用量。豆包 ASR / AST 尚未接入。
- **完整的音频文件自动解码与切分需要本机安装 FFmpeg 和 ffprobe，安装包未内置。** 缺少工具时可使用页面中的“导入已切分音频”。
- 原文件本地分段上限为 16 GiB / 24 小时；手动导入的单个文件上限为 100 MiB / 30 分钟。实际翻译速度受网络、提供商限流和录音长度影响。
- 发送译音到会议软件需要另行安装虚拟音频驱动，并在翻译器及会议软件内选择对应设备。Windows ARM64 需要兼容 ARM64 的驱动。
- macOS 实时采集需要授予麦克风及录屏与系统录音权限；上传文件翻译不需要这两项采集权限。
- macOS 使用 ad-hoc 签名，未经 Apple 开发者签名及公证；Windows 安装包未使用发行者证书签名。
- 本仓库暂未配置自动更新发布，请从 Releases 手动下载。文件翻译结果和恢复队列只保留在当前窗口，退出前请导出字幕。

## 验证范围

- 发布前本地通过 209 项 JavaScript 测试；当前功能已通过 27 项 macOS 原生 Rust 测试及 Apple Silicon 调试版构建。
- 本地模拟服务验证了“其他片段成功、单个请求失败、跳过失败片段、单独重试成功”，确认其他已完成字幕不会重复。
- 发布工作流对 macOS Apple Silicon 和 Windows ARM64 分别执行 JavaScript / Rust 测试、构建及二进制架构和版本检查，成功后发布安装包。
- 构建及模拟测试不等于真实云端翻译、时间对齐质量或目标设备会议通话验收；仍需使用自己的账号、录音及音频设备验证。
