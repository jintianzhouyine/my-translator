Fix the native compilation failure in v0.10.7. Includes its live translation recovery and seven-day diagnostic logs.

## Fixes

- Fix Tauri error `E0277` caused by the audio capture command's error-channel parameter. The channel is now required; capture failures still notify the UI and stop the failed session.
- Supply the error channel during the local translation permission probe, with regression coverage for both the probe and live capture startup.
- Retain Qwen duplex, OpenAI and Soniox recovery, plus **设置 → 关于 → 打开日志目录** (Settings → About → Open log folder). Logs retain today and the preceding six dates. The default Windows directory is `%APPDATA%\com.personal.translator\logs`.

## Manual build

This Release is a draft; no build is automatically triggered. In [Build & Release](https://github.com/jintianzhouyine/my-translator/actions/workflows/release.yml), select **main** and enter **`v0.10.8`**.

Use the new tag. Rerunning `v0.10.7` still builds the original failing revision. After both platforms pass, the workflow uploads and publishes:

- `MyTranslator_0.10.8_aarch64.dmg`
- `MyTranslator_0.10.8_x64-setup.exe`
- `SHA256SUMS`

## Validation scope

All 345 JavaScript application tests passed, including required-channel regression coverage for local permission probing and live capture. Changed Rust file formatting, diff checks and strict LeanSpec validation passed.

Full native testing is still blocked locally by dependency-index downloads. Complete macOS and Windows builds and installers depend on this manual CI run. Real cloud and meeting-device behavior still requires testing on target machines.
