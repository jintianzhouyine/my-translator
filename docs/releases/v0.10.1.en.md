Windows releases switch to Intel/AMD 64-bit x64, alongside macOS Apple Silicon installers.

## Downloads

- **Apple Silicon Mac**: `MyTranslator_0.10.1_aarch64.dmg`.
- **Windows x64**: `MyTranslator_0.10.1_x64-setup.exe`, for 64-bit Intel/AMD PCs. This is not a 32-bit x86 application.
- `SHA256SUMS` contains SHA-256 checksums for both installers.
- This version does not provide a native Windows ARM64 installer. The historical ARM64 release is available in [v0.10.0](https://github.com/jintianzhouyine/my-translator/releases/tag/v0.10.0).

## Changes

- Changed the Windows build target to `x86_64-pc-windows-msvc`, verifying that the application PE architecture is AMD64.
- Changed the release workflow to manual dispatch: provide an existing version tag, and the workflow uploads installers and publishes the draft after both platforms pass.
- Added regression tests for architecture and version checks, and updated platform downloads and release instructions.
- Initialized LeanSpec project specifications to record requirements, design decisions and acceptance checks.
- Retained v0.10.0's Qwen duplex calls, terminology imports, audio-file translation, subtitle exports and failed-segment retries.

## Usage notes

- Qwen requires your own Alibaba Cloud Bailian API key, workspace and region.
- Automatic audio decoding and splitting require FFmpeg / ffprobe installed locally; they are not bundled.
- Sending translated speech to a meeting application requires a separately installed virtual audio driver compatible with your system architecture.
- macOS uses an ad-hoc signature, without an Apple Developer signature or notarization. The Windows installer has no publisher certificate.
- Download updates manually from Releases. Doubao ASR / AST is not integrated.

## Release and validation

At the draft stage, installers for this version are not yet available; a maintainer must manually trigger the build.
The workflow runs JavaScript / Rust tests, builds, and architecture and version checks for both platforms, then uploads files and publishes after success.
Real cloud translation, installation and meeting audio routing still require validation on target computers.
