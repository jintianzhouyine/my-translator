Windows 发布目标切换为 Intel/AMD 64 位 x64，保留 macOS M 系列安装包。

## 下载

- **Mac M 系列**：`MyTranslator_0.10.1_aarch64.dmg`。
- **Windows x64**：`MyTranslator_0.10.1_x64-setup.exe`，适用于 64 位 Intel/AMD 电脑，不是 32 位 x86 程序。
- `SHA256SUMS` 提供两个安装包的 SHA-256 校验值。
- 本版不提供原生 Windows ARM64 安装包；历史 ARM64 版本可从 [v0.10.0](https://github.com/jintianzhouyine/my-translator/releases/tag/v0.10.0) 下载。

## 更新内容

- Windows 构建改为 `x86_64-pc-windows-msvc`，检查应用程序 PE 架构为 AMD64。
- 发布工作流改为手动触发：指定已有版本 tag，两个平台均通过后上传安装包并发布草稿。
- 增加架构及版本校验的回归测试，更新平台下载和发布操作说明。
- 初始化 LeanSpec 项目规范，方便后续记录需求、设计与验收。
- 保留 v0.10.0 的 Qwen 双向通话、术语导入、音频文件翻译、字幕导出及失败片段重试功能。

## 使用说明

- Qwen 功能需配置自己的阿里云百炼 API Key、业务空间和地域。
- 音频自动解码和切分需要本机安装 FFmpeg / ffprobe，安装包未内置。
- 向会议软件发送译音需要另外安装与系统架构兼容的虚拟音频驱动。
- macOS 使用 ad-hoc 签名，未经 Apple 开发者签名和公证；Windows 安装包未使用发行者证书签名。
- 从 Releases 手动下载更新；豆包 ASR / AST 尚未接入。

## 发布与验证

草稿阶段尚无本版安装包，需要维护者手动触发构建。
工作流执行两个平台的 JavaScript / Rust 测试、构建、架构和版本检查，成功后上传文件并正式发布。
真实云端翻译、安装体验和会议音频路由仍需在目标电脑上验证。
