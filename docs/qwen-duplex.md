# Qwen 双向通话翻译

此模式只需在自己的电脑运行。对方继续使用原有会议软件。

- 你的麦克风 → Qwen 翻译和生成译音 → 虚拟音频输出 → 会议软件的麦克风。
- 对方的会议声音 → 独立 Qwen 会话 → 本机原文和翻译字幕。

使用云端 `qwen3.8-livetranslate-flash-realtime`，需要联网及百炼 API Key。两条方向分别建立会话、分别计量调用用量。字幕模式支持 60 种目标语言，译音支持其中 29 种；中文和英语均支持。此模式直接使用 Qwen 译音，无需额外 TTS 服务或 Piper 模型。

## 配置

1. 打开「设置 → 翻译引擎」，选择「Qwen3.8 实时通话翻译」。
2. 填写百炼 API Key、业务空间 ID 和服务地域。密钥和业务空间必须属于同一所选地域，支持北京与新加坡。
3. 设置「我阅读字幕的语言」与「对方听到的语言」。双向通话的两个目标语言须不同；Qwen 自动识别输入语种。
4. 选择真实麦克风，将「发给对方的译音输出」设为已经安装的虚拟音频设备。
5. 在会议软件中，将该虚拟设备对应的输入设为麦克风。会议扬声器设为自己的耳机。
6. 保存设置后开始翻译。若只需看对方字幕，可关闭「双向通话」；此时不采集自己的麦克风、不生成译音，也不需要虚拟音频设备。

输出设备必须明确选择；不会在设备缺失时自动切换到扬声器。安装设备后点击「刷新设备」。本软件不自动安装音频驱动，也不替你修改会议软件的设备设置。

## macOS 与 Windows 的路由

macOS 可以使用已经安装的 BlackHole 等虚拟音频设备：翻译器将译音写入虚拟设备，会议软件从同一虚拟设备读取麦克风。系统音频通过 ScreenCaptureKit 采集，并排除本软件自身播放的声音。首次使用需授予系统音频采集和麦克风权限。

Windows 可以使用兼容当前系统架构的虚拟音频线：翻译器选择其播放端作为译音输出，会议软件选择对应的录音端作为麦克风；两端名称可能不同。系统声音采集设备应是会议软件播放对方声音的耳机。它必须与译音输出分开，否则译音会被重复识别。Windows ARM 设备应确认驱动本身支持 ARM64。

两种系统都建议使用耳机。排除软件输出不能阻止扬声器声音通过空气进入真实麦克风。

## 术语词典

两个方向的词典独立保存，不自动反转。每行填写一个映射，以第一个英文等号分隔原词和指定译法；译法中的后续等号会保留。

发给对方的词典示例：

```text
灰度发布 = canary release
产品名 = ProductName
```

本机字幕词典示例：

```text
canary release = 灰度发布
ProductName = 产品名
```

每个方向最多 1,000 条；重复原词、空原词或空译法会阻止保存。词典通过 `session.translation.corpus.phrases` 发送，用来提高术语准确率，不是保证每次完全一致的硬替换规则。运行中保存设置会先暂停翻译；重新点击开始后应用新配置。

### 从 Excel 导入

1. 在对应方向的词典旁点击「导入词表」，选择 `.xlsx` 文件。可从 [Excel 示例词表](examples/qwen-terms.xlsx) 开始修改。
2. 选择工作表，前两列分别为「原词」和「译法」。首行可使用 `原词、译法` 或 `source、target` 表头；没有表头也可以。其他列可填写备注，不会导入。
3. 检查预览。默认合并现有词典，同名词译法不同时保留现有译法；可改为覆盖冲突，或替换该方向的整份词典。相同重复项会去重，文件内同一原词对应不同译法时需先修正文件。
4. 如将同一份词表用于反向翻译，勾选「交换两列」。只会修改当前所选方向，另一方向保持原样。
5. 点击「确认导入」，再点击「保存并关闭」。正在翻译时保存会先暂停，重新开始后使用新词典。

文件只在本机读取，确认前不会修改词典。限制为每个文件 2 MiB、每个方向合并后最多 1,000 条、单个工作表最多 10,002 行（含空行）。Excel 前两列必须是文本或可显示的普通值，公式请先复制并粘贴为值；旧版 `.xls` 请另存为 `.xlsx`。只预览前 20 条，确认时导入全部有效词条。

也支持 UTF-8 或带 BOM 的 UTF-16 文本词表：CSV/TSV 使用两列，TXT 每行填写 `原词 = 译法`，JSON 使用 `{ "原词": "译法" }` 或 `[{ "source": "原词", "target": "译法" }]`。
